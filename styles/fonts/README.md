# Self-Hosted Font Assets

This folder contains the vendored webfont files used by the site.

- `IBM Plex Sans`
- `IBM Plex Mono`
- `Spectral`

These files are self-hosted so the site does not require client font requests to Google.

License notices are included alongside the files:

- [IBM-Plex-Mono-OFL.txt](./IBM-Plex-Mono-OFL.txt)
- [Spectral-OFL.txt](./Spectral-OFL.txt)
