Method

How the work happens

Records work usually starts with a request, expands into verification, and ends in a public case file people can follow.

1. Request

Pull the records first

Requests, agency logs, and document organization form the base layer before any public write-up begins.

2. Trace

Map the funding trail

Findings can connect agencies, facilities, companies, and local sites so readers can track a story spatially as well as chronologically.

3. Publish

Share the evidence cleanly

Published investigations should be readable to the public and useful to anyone following up with more records work.
